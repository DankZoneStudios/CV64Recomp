# Castlevania 64: Recompiled v0.6.0

This is a modified build of Castlevania 64: Recompiled based on the
CV64Recomp project and its upstream projects.

## Game ROM

No Castlevania 64 ROM or other original game ROM image is included.

To play, you must provide your own compatible North American Castlevania 64
Nintendo 64 ROM when prompted by the launcher.

## Source Code

The source code corresponding to this release is available from:

https://github.com/DankZoneStudios/CV64Recomp

The Git tag for this release is `v0.6.0`.
